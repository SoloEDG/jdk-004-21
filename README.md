# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 武器系统

每把武器独立维护弹匣、热量与恢复过程：

- 一次扳机循环消耗 1 发弹匣弹药；打空后进入**装填**，装填完成后按锁定时的弹匣容量补满。
- 每发都会累积热量；达到上限后进入**过热排放**，排放完成后热量归零。两者同一帧触发时只进入装填，剩余热量随后单独排放。
- 恢复完成的当帧不会开火，避免恢复结束后多打一轮。
- **超频回路**只缩短射击间隔，**快速装填**只缩短装填时间，两者独立叠加。
- 升级候选的数值预览、武器面板与实战发射都读取同一份 `weaponStats` 有效参数。
- 武器升级在升级暂停期间只入队，到下一发合法射击才生效；不会补满弹匣、不会重置装填，连续升级无法免费开火。
- 切换波次不会补弹；旧存档中只有 `{ id, level, cooldown }` 的武器按满弹匣迁移。
- 结算面板分别统计发射量与命中量。
